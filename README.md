# Blinkit Sales Dashboard (Power BI)

## 📊 Project Overview
Developed a comprehensive Power BI dashboard to analyze Blinkit grocery transactions and derive actionable business insights.  
The dashboard provides interactive visualizations, KPIs, and advanced filtering options to help business stakeholders understand sales trends, customer preferences, and outlet performance.

## 🔑 Key Features
- Defined and calculated KPIs:
  - **Total Sales**
  - **Average Sales per Item**
  - **Total Number of Items Sold**
  - **Average E-Rating**
- Built dynamic measures using advanced **DAX functions** for real-time, filterable insights.
- Integrated **slicers and filters** for outlet size, item type, location, and fat content to allow self-service analysis.

## 📈 Visualizations
The dashboard includes a variety of charts and visuals:
- **Donut Chart** → Item Fat Content Distribution  
- **Bar Chart** → Sales by Item Type  
- **Stacked Column Chart** → Fat Content by Outlet  
- **Line Chart** → Outlet Establishment Year Trend  
- **Funnel Map** → Location-wise Sales Distribution  
- **Matrix Card** → All KPIs by Outlet Type  

## 🚀 Business Impact
- Enabled **product mix optimization** and **outlet-specific performance reviews**.  
- Supported **marketing, inventory planning, and store-level strategy decisions**.  
- Helped identify:
  - High-performing outlet formats  
  - Top-selling item categories  
  - Potential focus areas for **health-conscious product marketing**
